# bmo-text

チャットルーム、コンソール、アーカイブが読むのと同じ形で、マークダウンとテキストを読み書きするベースライブラリです。
マークダウンから Telegram の HTML やプレーンテキストへの変換、マークアップの構造チェック、折りたたみとメッセージへの
分割、本文中の Web アドレス、ダッシュの書き換え、禁止語用語集に対するテキストのチェック、回答の上限、マークダウン文書の
構造、検索結果の構造行、翻訳器に渡すテキストの断片、そして HTML ページを行として読み取る処理を扱います。これらの読み取りは
Rust クレートに一度だけ書かれ、TypeScript パッケージはそのクレートを WebAssembly にビルドしたもので、Bun、Node、ブラウザの
いずれでも import 時に同期的に読み込まれます。長さは `chars` と名付けられていない限り UTF-16 単位で数え、空白と trim は
JavaScript に従うため、同じ入力に対して両者は同じ答えを返します。クレートのバイナリを `bmo-text mcp` として実行すると
MCP サーバーになり、`bmo-text` プラグインを与えられたコーディングハーネスはこれを通じて純粋な読み取り処理を呼び出します。

| フォルダ | 内容 |
|---|---|
| `docs/` | 設計、公開 API、境界、ライブラリの出自の一覧、ベース分離の計画、個人情報のルール |
| `src/` | Rust クレート `bmo-text` のソース。マニフェストはルートにあります |
| `tests/` | クレートのテストと、リポジトリ自身の形を保つリポジトリテスト |
| `package/` | TypeScript パッケージ `bmo-text`:クレートの WebAssembly ビルドの上に載るモジュール、`wasm/` 内のビルド、そのテスト |
| `cases/` | クレートとパッケージの両方が満たすべきケース。モジュールごとに 1 ファイル |
| `plugin/` | ハーネスプラグイン `bmo-text`:マニフェスト、MCP サーバーの設定、`bmo-text` スキル |

このライブラリはレジストリのパッケージ以外には依存せず、HTTP サーバーもデプロイもありません。利用側はクレートをパスか
git で、パッケージを依存関係として取り込み、自分で決めるべきもの、つまり読み手が目にする文言、英語のポリシー、用語集の
パスを渡します。

個人情報はコード、テスト、ドキュメント、コミットに含めません。`docs/PERSONAL-DATA.md` に、そのルールと、このリポジトリが
ルールを守っていることを確かめるチェックが書かれています。

このライブラリは MIT ライセンスで公開されており、全文は `LICENSE` にあります。

チェックとテストは `testbed.toml` に宣言されており、実行するコマンドは `CLAUDE.md` に記載されています。
